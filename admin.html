Chưa nhập Token
Cách lấy GitHub Token miễn phí (làm 1 lần trên điện thoại)
  1. Vào github.com/settings/tokens → Generate new token (classic).
  2. Đặt tên bất kỳ, chọn Expiration No expiration, tích ô repo.
  3. Bấm Generate token, copy mã dán vào ô trên rồi bấm Lưu Token.
